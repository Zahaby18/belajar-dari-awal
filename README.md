# BOOTCAMP ZAHAB - PETA FOLDER

## Folder kamu (yang kamu KERJAKAN)
**`latihan/`** - ini tempat kamu nulis kode. Semua file PHP kamu ada di sini.
- `00-mulai.php` <- KERJAKAN INI DULU (6 tugas kecil, 45 menit)
- `01-basics.php` <- nanti setelah 00-mulai kelar

Cara jalanin: `php latihan/00-mulai.php`
Kalau belum bisa jalanin PHP di komputermu: edit filenya, bilang "udah" di chat, gue yang jalanin dan kasih outputnya.

## Folder materi (yang kamu BACA)
**`sesi/`** - materi belajar, jangan diedit, cukup dibaca sambil ngerjain latihan.
- `001-php-survival.md` <- MULAI DARI SINI (cuma 6 aturan syntax)
- `001-php-dasar.md` <- versi lebih berat, tunda dulu

## Folder catatan (diisi mentor)
**`log/`** - catatan hasil tiap sesi: apa yang dikerjakan, apa yang salah, target berikutnya.
- `sesi-000.md` - tugas diagnosa
- `sesi-000-HASIL.md` - penilaian kamu + koreksi 14 jawaban

## File di root (aturan main)
- `00-CARA-KERJA.md` - 5 aturan main + ritme tiap sesi + cara nanya yang benar
- `01-DIAGNOSTIK.md` - soal diagnosa yang sudah kamu kerjakan
- `02-KURIKULUM-LEVEL.md` - peta Level 0 sampai Level 4 (jago banget) + gerbang naik level

---

## Alur kerja kita
1. Gue tulis materi di `sesi/` + kerangka tugas di `latihan/`
2. Kamu isi `latihan/` sambil baca `sesi/`
3. Kamu bilang "udah" (+ tulis kalau ada yang mentok)
4. Gue jalanin kodenya, kasih output, dan review: 3 hal yang harus diperbaiki
5. Gue catat di `log/`, lanjut sesi berikutnya

## Aturan yang berlaku
- **Kamu yang nulis kode.** Gue kasih satu langkah kalau kamu mentok, bukan jawaban utuh.
- **Tiap sesi harus ada commit.** Nggak ada commit = sesi itu nggak terjadi.
- Mentok > 20 menit = tanya. Nanya itu bukan curang, itu gunanya mentor.
- AI boleh buat nanya konsep, nggak boleh buat nulis kode kamu.
